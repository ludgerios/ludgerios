# Ícones de tecnologias

28 ícones locais com largura e altura de 40 px. A placa tem fundo `#0d1117`, borda `#a855f7` e cantos transparentes. Os nomes ficam no Markdown do perfil, fora dos arquivos de imagem.

Os desenhos oficiais foram preservados: sem recorte, rotação ou mudança das proporções. As versões coloridas do Devicon mantêm suas cores; os símbolos monocromáticos de Fastify e GitHub usam `#58a6ff` para contraste. Teams usa a cor de marca `#6264A7` e Power BI usa `#F2C811`.

ServiceNow contém o favicon original de 48 × 48 px do site oficial, decodificado sem perda para PNG e incorporado no próprio SVG. Esse arquivo não tem dependência de imagem externa. Todos os demais ícones usam geometria SVG.
