# Badges de competências

Badges estáticos obtidos pelo serviço [Shields.io](https://shields.io/), com estilo `flat-square`, fundo uniforme e altura de exibição de 24 px. Eles ficam neste repositório para evitar uma requisição externa por tecnologia durante a leitura do perfil.

Os logotipos disponíveis vêm de [Simple Icons](https://simpleicons.org/), cujo conjunto é distribuído sob [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Nomes, logotipos e marcas pertencem aos respectivos titulares. O código do Shields.io tem licenças [MIT](https://github.com/badges/shields/blob/master/LICENSE-MIT) e [Apache 2.0](https://github.com/badges/shields/blob/master/LICENSE-APACHE).
